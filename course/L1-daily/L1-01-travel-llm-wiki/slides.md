## 위키는 쌓이고, 바뀔 때 같이 바뀐다

| 문서 올려서 묻기 | LLM 위키 |
|---|---|
| 질문마다 처음부터 다시 찾기 | 정리해서 파일로 남김 |
| 아무것도 안 쌓임 | 장소마다 페이지 + 서로 연결 |
| | 새 정보 → 관련 페이지 **함께** 수정 |

**대화는 사라지지만, 위키는 쌓인다**

## 위키를 근거로 계획이 나온다

> 6월에 가족이랑 3박 4일 도쿄 여행 계획 짜줘.
> 동행자는 6세 아이와 아내 둘이야.

- 6살 아이 → 걷는 거리 줄이고 쉬는 시간
- 내 취향 프로필 반영
- 아사쿠사·긴자 페이지로 링크

<!-- DEMO: 입력 → 빨리감기 → 일정 파일, 아이 관련 부분 하이라이트 -->
