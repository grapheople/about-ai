# 강사 인터뷰 — 경력과 AI 코딩 체험 변천사

12년차 서버 개발자인 강사가 AI 코딩 도구를 "일부 로직 보조 → 업무 보조 → 대부분 위임"으로 받아들여 온 1인칭 변천사.
도구가 계속 바뀌는 와중에 "변하지 않는 가치는 무엇인가"라는 고민이 LLM 위키로 이어진다. **개인 경험·의견이다.**

## 핵심 내용
- 2014년 대형 포털 신입 입사 → 커머스 플랫폼 → 건강 플랫폼 스타트업 → 현재 대기업 산하 헬스케어 플랫폼 회사(커머스 플랫폼 개발 담당). 12년차, 서버 개발 중심 경력.
- 2021년 코로나 팬데믹 때 대기업 씬을 떠나 학교 선후배들과 건강 플랫폼 스타트업 합류.
- 2022년 무렵 GitHub Copilot 등으로 AI 코딩 보조를 처음 사용. 숙달도·신뢰 부족으로 **함수 안 일부 로직** 수정만 맡김.
- 2023년 GPT-4 이후 쓸 만한 업무 보조를 받았지만 **완전한 위임은 못 함**.
- 2025년 초 Claude Code 등장 후 패러다임 전환 — 체감상 코딩은 사람 능력을 넘어섰고 대부분의 코딩을 AI로 한다.
- 스킬·플러그인 생태계와 프롬프트 → 컨텍스트 → 하네스 → 루프 엔지니어링으로 이어지는 방법론 변화를 겪는 중.
- 변화 속에서 "변하지 않는 가치는 무엇인가"를 고민 → Karpathy의 LLM 위키.

## 강의에 쓸 만한 포인트
- L1-01 도입부(강사 소개 → AI 코딩 변천사 → 변하지 않는 가치 → LLM 위키).
- L3 "개발 방식이 어떻게 바뀌었나" 레슨의 1인칭 타임라인.
