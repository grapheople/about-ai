# Obsidian 설치 안내 · 라이선스

macOS 설치는 다운로드 → Applications로 드래그. 개인·업무 모두 무료.

## 핵심 내용
- macOS: 다운로드 페이지에서 Universal 선택 → 설치 파일 열기 → Applications 폴더로 드래그 → 실행.
- "Obsidian is free for all purposes, including personal, commercial, and non-profit use." 유료 Commercial license는 선택.

## 강의에 쓸 만한 포인트
- L1-01 설치 ①: "Obsidian은 무료" 한 줄. 볼트 생성 화면은 공식 문서에 없어서 실제 화면 녹화로 보여 준다.
