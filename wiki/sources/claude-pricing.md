# Claude 요금제 (2026-10-21)

Claude Code는 유료 플랜(Pro 이상)에 포함되고 Free에는 없다. (as of 2026-10)

## 핵심 내용
- Free $0 — Claude Code 없음.
- Pro $20/월(월간) · $17/월(연간 $200) — Claude Code 포함.
- Max "From $100"/월 (5x·20x) — 포함.
- Team Standard $25/석(월간)·$20(연간), Premium $125·$100 — 포함.
- 2026-04 Pro에서 Claude Code를 빼는 소규모 테스트(신규 가입자 약 2%) 보도 → 정책 변동 가능성.

## 강의에 쓸 만한 포인트
- L1-01 준비물: "Claude Pro 이상 필요, 무료 플랜 불가 (촬영 시점 기준)".
