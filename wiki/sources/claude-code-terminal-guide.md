# Claude Code 터미널 초보자 가이드

터미널을 처음 쓰는 사람을 위한 공식 단계별 안내. L1-01 설치 구간 대본의 직접 근거. (as of 2026-10)

## 핵심 내용 (macOS)
1. `Cmd + Space` → "Terminal" 입력 → `Enter`. 커서가 깜빡이는 창이 터미널.
2. 설치 명령을 복사 → `Cmd + V`로 붙여넣기 → `Enter`. 진행 표시가 없으니 창을 열어 두고 기다린다. 끝나면 "Claude Code successfully installed!"
3. `claude` 입력 → 로그인 안내 → 브라우저에서 로그인.
4. 알아둘 것: 터미널에서는 클릭이 안 되고 화살표 키로 이동, `Esc`로 중단, `exit`로 종료, `/help`로 명령 보기.
- `command not found: claude`가 나오면 PATH 문제 → 문서의 해결법 후 새 터미널 창.
- "You don't need to know how to code. Describe what you want in plain English."

## 강의에 쓸 만한 포인트
- L1-01 설치 ② 구간을 이 4단계 그대로 따라간다.
- 문서 상단에 "터미널이 싫으면 Desktop 앱" 안내가 있다 → [[tools/claude-code]]의 미확인 항목 참고.
