# Obsidian

내 컴퓨터의 폴더(볼트) 안 마크다운 파일을 노트로 보여 주는 앱. 노트 간 링크와 **그래프 뷰**로 지식의 연결을 눈으로 볼 수 있다.
개인·업무 모두 무료.

## 본문
- 설치(macOS): 다운로드 페이지 → Universal → Applications로 드래그 → 실행.
- 라이선스: "free for all purposes, including personal, commercial" (2025-02-20 기준).
- LLM 위키에서의 역할: Karpathy — "Obsidian은 IDE, LLM은 프로그래머, 위키는 코드베이스". 사람은 Obsidian으로 읽고 링크를 따라가며, LLM이 파일을 쓴다.
- 유용한 기능 (Karpathy 팁): 그래프 뷰(허브·고아 페이지 확인), Web Clipper(웹 글 → 마크다운), Dataview(frontmatter 질의), Marp(슬라이드).
- 볼트 = 그냥 폴더. git으로 버전 관리 가능.
- [[tools/claudian]]을 설치하면 Obsidian 안에서 Claude와 대화할 수 있다 (v1.13.0+ 필요).
