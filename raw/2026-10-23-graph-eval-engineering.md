# 그래프 엔지니어링 · 이밸 엔지니어링 — 웹 확인 메모

## 그래프 엔지니어링 (Graph Engineering)
- arXiv 2608.21156 "Graph Engineering in the Era of LLM Agents: From Individual Intelligence to System Intelligence"
  (Yuyuan Feng 외 35명, v1 2026-08-21, v2 2026-08-26).
- 정의: 작업·에이전트·시스템 상태를 나타내는 명시적이고 동적으로 진화하는 그래프 구조를 만들어,
  복잡한 목표를 조직하고 여러 이질적인 에이전트를 조율하는 차세대 에이전트 시스템 패러다임.
- 앞 패러다임과의 관계(초록): 프롬프트 = 모델 능력 끌어내기, 컨텍스트 = 접근 정보 관리,
  하네스 = 외부 도구·자원 조직, 루프 = 지속적 성찰·자기 개선. 이들은 주로 단일 에이전트를 최적화하고,
  그래프 엔지니어링은 여러 에이전트의 협업("System Intelligence")을 다룬다.
- 출처: https://arxiv.org/abs/2608.21156

## 이밸 엔지니어링 (Eval Engineering)
- 하나로 합의된 정의는 아직 없다. 대부분 벤더·블로그 출처.
- 공통 의미: LLM 앱, 특히 에이전트에 대한 평가(eval)를 설계·실행·운영하는 실천.
  실제 사용자에게 닿기 전에 현실적인 시나리오 테스트를 자동으로 계속 돌린다.
- 에이전트 평가는 최종 답만이 아니라 여러 단계 추론·도구 사용·경로(trajectory) 품질을 본다. LLM-as-a-judge가 흔한 기법.
- SiliconANGLE(2026-05-17): 독립된 검증 에이전트들이 각 에이전트의 수행을 평가하는 방식으로 에이전트를 거버넌스한다.
- 출처: https://siliconangle.com/2026/05/17/eval-engineering-missing-piece-agentic-ai-governance/ ,
