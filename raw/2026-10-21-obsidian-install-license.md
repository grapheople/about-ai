# Obsidian 설치·라이선스 (2026-10-21 캡처)

## macOS 설치 (help/install)
1. 브라우저에서 Obsidian 다운로드 페이지로 이동
2. macOS의 Universal 다운로드 선택
3. 설치 파일 열기
4. "In the window that opens, drag Obsidian to the Applications folder."
5. 다른 앱처럼 실행

설치 페이지에는 볼트 생성·시스템 요구사항 설명 없음.
